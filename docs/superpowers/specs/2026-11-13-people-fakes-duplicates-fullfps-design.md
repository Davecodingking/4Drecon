# 人体：假人、重复人、帧率跟原片（2026-11-13）

## 背景

jw4 r4_30fps（人体全帧）里出现两类问题：
- 18.8～19.5 秒，长发打手身上叠了两个人（人 3 + 人 7）。
- 人 8 只有 3 帧（一闪而过的模糊人影 + 一根棍子），30 fps 下闪 0.1 秒。

另外，人体帧率以前跟着场景抽帧走（室内 120 帧 ≈ 6 fps），人体本身没有理由抽帧。

## 决定

### 1. 重复人：编号跳到已有的人身上（people_identity.resolve）

- 判据：一组里有"瞬移 / 跟丢之后切出来的段"（jump_cut），并且这组位置可信的帧里，≥ `DUP_FRAC` = 50% 和一个已经确认的人同一帧骨盆水平距离 < `DUP_M` = 0.3 m。
- 处理：这组不算人，记进去向表（"编号 N 跳到了人 X 身上……一个人挂了两个编号"）。
- 为什么不用"身体重叠比例"：真人抱在一起扭打时，重建出来的身体会互相穿插，重叠也能到 0.5～0.98（jw1 第 326～338、369、634 帧），会误删真人。真人从头就有自己的编号，不是跳过来的。

### 2. 短命假人：按秒算（people_identity.MIN_PERSON_S = 0.25 s）

- 在场时间 = 帧数 × 帧间隔，不到 0.25 秒的不算人。
- 例外：片头或片尾连着露的那一下照样算人（nfl1 人 8 片尾才进画面，24 fps 3 帧 = 0.125 s，是真人）。
- 不到 `MIN_FRAMES` = 3 帧的照旧不算人。
- 场景那批帧（6～10 fps）里 3 帧 ≥ 0.3 秒，所以老轮次结果不变。

### 3. 人体帧率跟原片（PEOPLE_FULL）

- 新开的一轮（第一次写本轮配置时）默认 `PEOPLE_FULL=1`：人体跟踪、网格、摆人、验收视频、FBX 都用原片全帧。场景照旧抽帧，因为那是给算相机和深度用的。
- 已经有本轮配置的老轮次不加这一项，重跑结果不变；人体跟踪之前可以在本轮配置里关掉。
- 超长片子：人体帧数上限 `FULL_MAX` = 1800（30 fps 下 1 分钟），超过就按整数步长抽。
- 中间帧的相机：用前后两个场景相机插值（dense_cams.py），不跨切点；用到坏相机插出来的帧也算坏。

## 验证

- 测试：`tools/tests/test_people_identity.py`（+5 条）、`test_run_ctl.py` / `test_people_gate.py` / `test_run_page.py`（新轮次配置）。
- 身份回归（改前对比改后，33 个有人的轮次，只算身份）：
  - jw4 r4_30fps：人 7、人 8 去掉。
  - jw1 r1（老轮次）：有一个 3 帧、跳到人 10 身上的编号被去掉。
  - 其余 31 个轮次不变，包括 nfl1、goodfellas、soccer 这些 24～30 fps 的轮次。
- 数据和脚本：`data/indoorOutput/jw4_kitchen_indoor/r4_30fps/debug_1113/`（id_regress.py / id_regress.log / dup_survey.py）。
